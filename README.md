# zhiliangrjm-notes

Go · GraphQL · Rust

处理日常小任务的工具

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/zhiliangrjm-notes.git
cd zhiliangrjm-notes
pip install -r requirements.txt
```
